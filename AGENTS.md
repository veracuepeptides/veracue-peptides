# Veracue Project Guidelines

## Design & Color System

Strict color constraint: All design, styling, and SVG work across the application must strictly adhere to the following 7 brand colors:

- `#cb997e` — **Terracotta** (Primary accent, CTA hover states, conversion highlights)
- `#eddcd2` — **Almond** (Borders, card strokes, divider lines)
- `#fff1e6` — **Linen** (Light elevated card surfaces, badge fills, button text)
- `#f0efeb` — **Alabaster / Pebble** (Main page background)
- `#ddbea9` — **Warm Sand** (Intermediate warm badges, secondary chips)
- `#a5a58d` — **Olive Green / Sage** (Header background, global focus rings, lab badges)
- `#b7b7a4` — **Stone / Muted Sage** (Subtle borders, line art, muted captions)

Deep contrast surfaces use olive-charcoal `#20221c` or `#191b16`.
